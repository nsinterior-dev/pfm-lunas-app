# MVP 3 — Financial Literacy Layer

**Theme**: "Can the app teach me while it helps me?"

**Sprints**: TBD (Q3 2026+)

## Features

- Contextual knowledge cards — e.g. Debt Avalanche / Snowball surfaced automatically
- Source-backed guidance — BSP, SEC Philippines, Investopedia, etc.
- Interest calculators
- "What if" projections
- Glossary — plain-language financial term definitions
- Expanded prompt suggestions for literacy topics

## Success Criteria

- User learns at least one new financial concept per session
- Contextual cards appear without searching
- All sourced content links to verifiable references
